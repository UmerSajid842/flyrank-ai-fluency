How I work

Make the decision inspectable

Lead with the decision problem and link the public paper, report, charts, and repository so the work can be checked.

Name the boundary

Keep the data framing public-safe, state evaluation limits, and avoid claims that the evidence does not support.

Separate workspaces

ML Work and AI Work stay distinct.

This site focuses on the public machine-learning case study. The companion AI Work capstone page documents the evidence-safe portfolio agent, workflow, and safety boundaries; the AI Work repository contains the inspectable source and assignment evidence.
