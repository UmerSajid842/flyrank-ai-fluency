# Set Up the Claude Project for Umer Sajid’s ML and AI Work

## What this is for

Create one private Claude Project so Claude can keep the approved identity, portfolio messaging, and **public-safe** ML case-study context together. This is a personal-account action; do not upload datasets, client names, credentials, raw notebooks containing private material, or any other non-public file.

> Claude Projects are available on free Claude accounts. Free accounts can create up to five projects.[1]

## Create the Project

1. Open <https://claude.ai/projects> and sign in.
2. Select **+ New Project**.
3. Use this name: **Umer Sajid — ML Work & AI Work**.
4. Optional description: **Public-safe context for a machine-learning case study and AI Fluency portfolio work.**
5. Keep the Project private.

## Add these three files to Project Knowledge

On the Project page, find **Project knowledge** on the right side, click **+**, and upload the following files from this repository:

| Upload | Purpose | Repository path |
|---|---|---|
| `identity_kit.md` | Brand rules and exact style note | `ai_fluency/CUSTOM-MQX00WJN-0CE9EDFA/identity_kit.md` |
| `content_and_cta_map.md` | Approved claim, content order, CTA, and proof boundaries | `ai_fluency/CUSTOM-MQWZXUQU-B5F087BE/content_and_cta_map.md` |
| `portfolio_case_study_context.md` | Public-safe ML case-study facts and links | `ai_fluency/claude_project/portfolio_case_study_context.md` |

Claude uses content placed in Project Knowledge across chats in that Project.[1] Markdown files are acceptable as text documents; each project file must be 30 MB or less.[2]
