## Repeatable process for adding the next case

I will use the same three-beat shape from Week 2: **Problem → What I did → What came of it**.

| Step | Action | Completion check |
|---|---|---|
| 1. Prepare proof | Collect only public-safe materials: the decision problem, source-appropriate evidence, method notes, evaluation outputs, chart images, and known limitations. | Every claim can be traced to a real project artifact; no private data, client identifiers, or unsupported business outcomes are included. |
| 2. Write the three beats | Write a concise description of the problem, the data/tools/approach and decisions, then the measured result or useful lesson. | A reader can state the question, method, result, and limitation after reading the page. |
| 3. Build the page | Create `docs/marsvision-case-study.html` using the shared `site.css` and existing page structure. | The page uses the established typography, palette, navigation, and accessible controls. |
| 4. Connect it | Add a MarsVision case card to `docs/index.html`, update navigation to the case-study index, and link relevant project evidence or repository material. | The new case is reachable from the home page and the navigation without typing a URL. |
| 5. Verify before publishing | Check all internal/external links, image dimensions and clarity, desktop/tablet/mobile layouts, keyboard focus, and the public Vercel deployment. | No broken links, overflow, unreadable text, or invented claim remains. |
| 6. Publish the update | Commit the public-safe source and evidence to the portfolio repository; allow the Git-linked deployment to publish the update. | The live ML Work site shows the new case and the repository contains the corresponding source/evidence record. |

> **Three-beat content template**
>
> **Problem:** What decision or research question did MarsVision AI address, and why did it matter?
>
> **What I did:** What data, tools, modelling approach, validation design, and key design decisions did I use?
>
> **What came of it:** What measured result, limitation, recommendation, or lesson came from the work?
