# Portfolio Deployment Source

This directory is the static source for Umer Sajid’s portfolio landing page. It is intentionally near-blank while case-study evidence and personal-contact details are reviewed for accuracy and privacy.

The page uses the Week 3 identity system: Manrope, teal `#0F766E`, near-black `#172033`, off-white `#FAFAF8`, and coral `#F9735B`.

## Deployment

The public repository is linked to a Vercel project with `docs/` as its root directory. Updates to `docs/index.html` on `main` redeploy the static page. The deployed page links back to the repository, where the underlying AI Fluency work is publicly reviewable.
